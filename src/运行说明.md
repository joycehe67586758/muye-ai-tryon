# 运行说明（30 秒上手）

## 一、最快方式：双击

双击 **启动原型.bat**，浏览器会自动打开 `http://localhost:5173/`（评审首页）。

> 为什么必须这样：浏览器的硬性规定——**摄像头只能在 `localhost` 或 `https` 下打开**。
> 直接双击 HTML（`file://`）时摄像头会被浏览器拦截，其余功能正常。
> 服务是零依赖的 Node 静态服务，不需要 `npm install`。关闭黑窗口即停止。

## 二、看什么（评审路径）

1. **评审首页 `index.html`**：一页产品方案 + 原型入口，电脑上直接读，字号是正常网页字号。
2. **大屏原型** `AI虚拟试衣-大屏原型.html`
   - 点击「大屏全屏演示」进入 1080×1920 竖屏全屏（按 `Esc` 退出）。
   - 右上角「手机端预览」，右侧「演示控制」可一键触发失败、慢网络、自动清屏、授权被拒。
3. **手机端原型** `AI虚拟试衣-手机端原型.html`
   - 支持参数：`?code=取件码&avatar=m3&items=g1,g8`，与大屏结果页同源。
4. **真人试穿（摄像头）**
   - 大屏首页 →「开始试穿」→「真人试穿（需现场授权）」→「同意并开启摄像头」。
   - 浏览器询问权限时选择「允许」；站到画面中间正对屏幕。
   - 没有摄像头 / 拒绝授权也不影响流程：会提示原因并回落到虚拟形象。
   - 想验证算法效果但手边没摄像头，可打开：`AI虚拟试衣-大屏原型.html?livemode=image&scr=live`

## 六、接入真实的换装模型（已实现，填参数即用）

页面右上角「隐私模式」那一行可以点，打开**换装模型设置**（手机端在「我的 → 换装模型」）。三种来源：

| 来源 | 说明 |
|---|---|
| 本地预览（默认） | 不配任何东西也能演示：直接用已生成的真人穿着照，保证现场不空手 |
| 自建换装服务 | 把 ComfyUI / CatVTON / IDM-VTON 包一层 HTTP，填端点即用 |
| fal.ai 托管模型 | 填 API Key，默认 `fal-ai/cat-vton`，走托管 GPU、按次计费 |

**自建服务的协议**（POST JSON）：

```
请求  { human_image, garment_image, garment_description, body:{height,shape,size}, seed }
响应  { image_base64: "data:image/...;base64,..." }   或   { image_url: "https://..." }
```

`human_image` 是**按用户所选体型挑的数字模特**，`garment_image` 是商品图，`body` 是身形参数 —— 这就是"按体型生成"的落点。

联调（交付目录自带一个假的模型服务，可直接验证链路）：

```
node src/mock-model-server.js 5199
# 然后在换装模型设置里选「自建换装服务」，端点填 http://localhost:5199/generate，点「测试连接」
```

实测结果：服务端能收到带体型参数的请求（`body={"height":168,"shape":"运动","size":"M"}`），页面结果区显示的是模型返回的图片。

调用失败时不会白屏：自动回落到本地预览，并保留「重新生成 / 静态搭配图 / 稍后发到手机」三条兜底。

## 七、自动化测试

## 七、顾客本人拍照试穿（商场大屏）

大屏待机页有三个入口：**开始试穿（虚拟形象）**、**实时试衣镜（站在屏前 0 秒看效果）**、**用我的照片试穿**。

拍照试穿的路径：

1. 点「用我的照片试穿」→ 先出现告知（照片用途、是否上传、删除时机），同意后进入拍照页；
2. 站到虚线框内，画面会做**全身识别**，识别到头顶到脚都在框里时框会变绿、提示"可以拍"；
3. 点「拍摄并开始试穿」，或点「3 秒倒计时拍摄」；
4. 照片**留在本机**（base64，不落盘），自动进入选衣服；
5. 生成时：<b>用这张照片作为换装模型的人像输入</b>（`human_image`），并带上你选的身形参数 → 出"你穿这件"的效果图；
6. 没接模型时用**本机合成预览**（照片 + 服装图层，按拍照时的姿态对齐），结果页会标注「基于你的照片 · 本地合成预览」，不会假装是模型生成；
7. 60 秒自动清除画面 / 无操作 90 秒清屏 / 重置都会**一并清掉这张照片**。

隐私口径：照片默认不出屏、不上传；只有在设置里接入云端换装模型时才会发送到模型服务，且拍照页会明示"发送到模型服务、仅用于本次生成、生成后删除"，并需要勾选同意。

实测（Chrome 假摄像头）：拍照页出画面 ✓ 全身识别 ✓ 拍摄拿到本机照片 ✓ 生成后结果图基于顾客照片 ✓ 重置后照片被清除 ✓ —— 9 项全通过。

## 五、已知限制（写在明处）

- 实时试衣是**本地实时合成**（真实服装图贴合到肩线），用于快速看版型与颜色；**照片级成图**需要云端换装模型（IDM-VTON / CatVTON 类），原型里对应的入口是「生成高清效果图」，可用于讲成本与延迟取舍。
- 姿态追踪依赖网络加载 MediaPipe（首次约 2–5 秒）；加载失败时会自动切到手动模式，可用拖动与滚轮调整衣服位置。
- 素材为 AI 生成（无真人肖像、无第三方版权图）；演示用的短链域名 `m.muye.com` 为示例。
- 二维码是真实可扫的，内容是取件码与所选商品；生产环境替换为公司短链 + 一次性 token。
