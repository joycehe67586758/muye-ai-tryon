这块屏幕会用到你的什么数据？

默认情况下，我们不采集你的任何生物特征，试穿用的是你选的虚拟形象。

  • 默认虚拟形象：你只选择身高体型档位，系统不拍照、不认识你是谁，大屏上不留存任何个人信息。
  • 真人试穿（可选）：只有你主动点开并勾选授权后才会开启摄像头，画面只用于当场生成形象，在本机完成处理、不上传、不入库、不用于模型训练，生成结束立即丢弃原始帧。
  • 结果图保存：效果图在屏幕上只停留 60 秒，倒计时结束自动清除回到待机页；你也可以随时点"立即清除"。
  • 带走方式：只有扫码后结果才会存到你自己手机里；取件码 7 天有效、一次性，不填手机号也能用；不扫码就什么都不留。
  • 无操作清屏：连续 90 秒没有操作，屏幕自动清屏回到首页，避免你的选择被后面的人看到。
  • 删除权：手机端页面底部提供"删除我的试穿数据"，一键删除，立即生效。

开启真人试穿？

会让效果更像你，但需要你同意下面这件事。不同意也没关系，虚拟形象同样能看版型。

  • 摄像头只在生成形象时开启一次（约 3 秒），完成后立即关闭。
  • 画面只在本机处理，不上传、不保存、不用于训练；原始帧生成后立刻删除。
  • 生成的形象只属于这一次试穿，60 秒后随大屏画面一起清除。
  • 随时可以点屏幕上的"关闭摄像头"中止，也可以直接选虚拟形象。

换装模型设置

默认"本地预览"用已生成的真人穿着照，保证现场不空手；填上端点或 key 就是真的换装模型，按所选体型生成。

  • 自建服务：把 ComfyUI / CatVTON / IDM-VTON 包一层 HTTP：POST 收 human_image / garment_image / garment_description / body / seed，返回 image_base64 或 image_url。交付目录里带了一个 src/mock-model-server.js 可直接联调。
  • fal.ai：填 API Key，模型默认 fal-ai/cat-vton，走托管 GPU、按次计费。
  • 未配置或调用失败会自动回落本地预览，并保留"重试 / 静态搭配 / 推到手机"三条兜底。

手机端：把效果图变成一次决策

大屏负责"看到"，手机负责"看完并买下"。扫码后打开的就是下面这一页。

  • 效果图 + 取件码：7 天有效，随时回来接着看。
  • 尺码与库存：按你的身形给尺码建议，并显示本店现货数量。
  • 三种收口：加入购物车、预约到店试衣、加导购企业微信。
  • 隐私可控：底部一键删除本次试穿数据。
